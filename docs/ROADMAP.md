# Roadmap

## 0.1.x

- Stabilize macOS, Ubuntu/Debian, and WSL2 installation.
- Expand test fixtures for distribution and package-manager differences.
- Add more neutral module examples without introducing identity or company profiles.

## Later

- Evaluate native PowerShell support separately from WSL2.
- Consider additional Linux package managers after maintainers can test them.
- Add optional editor modules only when they have portable defaults and local override paths.
